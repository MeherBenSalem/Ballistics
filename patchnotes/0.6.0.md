# Remnants: Ballistics 0.6.0 — Minecraft 1.20.1

Remnants: Ballistics now runs on **Minecraft 1.20.1**, on Forge and Fabric, alongside 1.21.1, 26.2 and 26.3.

## New Minecraft version

- Builds for Minecraft 1.20.1 for Forge and Fabric, with the same weapons, attachments, stations, crafting, loot, advancements, animations, HUD and multiplayer behaviour as the other versions.
- Minecraft 1.20.1: Forge 47.1 or newer, or Fabric Loader 0.16.14 or newer with [Fabric API](https://modrinth.com/mod/fabric-api) and [Forge Config API Port](https://modrinth.com/mod/forge-config-api-port) 8.0.3 or newer.
- The Forge build also loads on NeoForge's 1.20.1 version (47.1.x).
- Minecraft 1.20.1 runs on Java 17.
- The 1.21.1, 26.2 and 26.3 builds for NeoForge and Fabric continue, with the same content.
- Each download is for one Minecraft version and one loader. The server and every client must use the same Minecraft version and loader.

## On 1.20.1

- There is no in-game config screen: edit `remnants_ballistics-client.toml` and `remnants_ballistics-common.toml` in `config/`, and `remnants_ballistics-server.toml` in `<world>/serverconfig/` (on Fabric, Forge Config API Port keeps it in `config/`). The settings are the same as on the other versions.
- Recipes that use steel or brass ingots accept `c:steel_ingots` / `c:brass_ingots` and Forge's `forge:ingots/steel` / `forge:ingots/brass`, so other mods' ingots work on both loaders.
- A weapon's loaded rounds, fire mode and attachments are stored in its NBT. Moving a 1.20.1 world to a newer Minecraft version keeps the weapons, but they come back empty, in their default fire mode and with their factory attachments, and fitted attachments are lost. Take attachments off before upgrading a world.

## Fixes

- Ammunition press recipes no longer log an "Unknown recipe category" warning for each recipe every time a player joins (1.20.1 and 1.21.1).

## Under the hood

- New `1.20.1/` workspace in the same MultiLoader layout, with a `forge` project in place of `neoforge`. The Forge jar is reobfuscated to Forge's runtime names, and aim sensitivity uses a small client mixin (Forge 1.20.1 has no event for it).
- Its assets and data are ported from the generated 1.21.1 resources by `tools/assets/port_resources.py` and checked by `tools/assets/check_assets.py`.
- Unit tests, GameTests on both loaders, the scripted client smoke test and jar verification run for all four Minecraft versions in CI, and each release ships eight jars.

## Upgrading

- Item, block, sound and config ids are the same on every Minecraft version and loader.
- Back up worlds before moving them to a new Minecraft version.
