# Remnants: Ballistics 0.4.0 — Fabric & Real Gunfire

Remnants: Ballistics now runs on **Fabric** as well as NeoForge, and every firearm sounds like the real thing.

## Fabric support

- A Fabric build for Minecraft 1.21.1 with the same weapons, attachments, stations, crafting, loot, animations, HUD and multiplayer behaviour as the NeoForge build.
- Requires Fabric Loader 0.16.14 or newer, [Fabric API](https://modrinth.com/mod/fabric-api) and [Forge Config API Port](https://modrinth.com/mod/forge-config-api-port) 21.1.6 or newer. [Mod Menu](https://modrinth.com/mod/modmenu) is optional and opens the in-game config screen.
- Both loaders read the same config files (`remnants_ballistics-client.toml`, `-common.toml` and the per-world `-server.toml`), and the server config syncs to clients on both.
- The server and every client must use the same loader.

## Sound

- Every firearm shot has been replaced with real-recording style audio: all 14 firearms plus the suppressed and distant reports, three variants each.
- All 22 handling sounds are new too: magazines, slides, bolts, pumps, revolver cylinders, feed covers, brass and shells, dry fire, fire-mode switches, jams, drawing, aiming and inspecting. Each mechanical sound's main click lands on its animation keyframe.
- Loudness matches the previous sounds, so the mix and the `mechanicalVolume` setting behave as before.
- Energy weapons, bullet impacts, UI and block sounds are unchanged.
- The new sounds were made with ElevenLabs (credited in NOTICE).

## Under the hood

- The 1.21.1 workspace now uses the MultiLoader layout of the other NightBeam mods: shared `common` code plus thin `fabric` and `neoforge` projects.
- The GameTests and the scripted client smoke test run on both loaders in CI, and each release ships one jar per loader.
- Recipes carry the Fabric and NeoForge forms of their config conditions, so the crafting toggles work on both.

## Upgrading

- NeoForge worlds and configs from 0.3.0 carry over unchanged: item, block and sound ids are the same.
