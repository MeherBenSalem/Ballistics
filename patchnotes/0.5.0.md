# Remnants: Ballistics 0.5.0 — Minecraft 26.2 & 26.3

Remnants: Ballistics now runs on **Minecraft 26.2 and 26.3**, on both NeoForge and Fabric, alongside 1.21.1.

## New Minecraft versions

- Builds for Minecraft 26.2 and 26.3, each for NeoForge and Fabric, with the same weapons, attachments, stations, crafting, loot, advancements, animations, HUD and multiplayer behaviour as the 1.21.1 builds.
- Minecraft 26.2: NeoForge 26.2.0.93 or newer, or Fabric Loader 0.19.5 or newer with [Fabric API](https://modrinth.com/mod/fabric-api) and [Forge Config API Port](https://modrinth.com/mod/forge-config-api-port) 26.2.1 or newer.
- Minecraft 26.3: NeoForge 26.3.0.99 or newer, or Fabric Loader 0.19.5 or newer with Fabric API and Forge Config API Port 26.3.1 or newer.
- These Minecraft versions run on Java 25.
- The 1.21.1 builds for NeoForge and Fabric continue, with the same content.
- Each download is for one Minecraft version and one loader. The server and every client must use the same Minecraft version and loader.

## On 26.2 and 26.3

- Weapons show their flat icon in inventories, the hotbar and other screens, and the animated 3D model in hand and on other players.
- The Gunsmith Workbench preview, the weapon HUD, first-person viewmodels, muzzle flashes, tracers, impacts and the Voidcaster orb render through the new 26.x rendering pipeline.
- Key bindings keep their own "Remnants: Ballistics" category in the controls screen.
- Config files keep their names (`remnants_ballistics-client.toml`, `-common.toml`, `-server.toml`). On NeoForge for 26.3, the server config lives in `config/` and can be overridden per world in `<world>/syncedconfig/`, which is where NeoForge now keeps synced configs.

## Under the hood

- New `26.2/` and `26.3/` workspaces in the same MultiLoader layout as `1.21.1/`. Their assets and data are ported from the generated 1.21.1 resources by `tools/assets/port_resources.py`, which rewrites the formats that changed (item model definitions, recipe ingredients, advancements and, on 26.3, loot conditions and modifiers).
- Unit tests, GameTests on both loaders and the scripted client smoke test run for all three Minecraft versions in CI, and each release ships six jars.
- A new GameTest checks that vanilla structure chests also roll the mod's loot, on both loaders.

## Upgrading

- Item, block, sound and config ids are the same on every Minecraft version and loader.
- Back up worlds before moving them to a new Minecraft version.
